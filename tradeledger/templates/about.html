What it does

TradeLedger is a trading journal. You record each trade's plan (entry, stop-loss, optional target, size) and, when it finishes, its exit. It then calculates the result of every closed trade and the performance of the whole journal.

How results are calculated

  • Net P&L = price move × position size × contract multiplier − fees, in the instrument's quote currency.
  • Realised R = net P&L ÷ initial risk, where initial risk is the money lost if the stop is hit.
  • A trade is a win if net P&L is above zero, a loss if below, and breakeven only at exactly zero.
  • Money in different currencies is never added together. R-multiples can be, because they are currency-neutral.
  • Every calculation uses exact decimal arithmetic in Python. The browser never calculates results.

Security and data

Each person signs in to their own account and sees only their own instruments, trades and analytics.

  • Passwords are stored only as Argon2id hashes. Repeated failed sign-ins are slowed down.
  • Every page with trading data needs a signed-in session; the JSON API needs a personal API token, which you can revoke at any time.
  • Every form is protected against cross-site request forgery, and pages may only load this site's own scripts and styles. The one exception is the analytics page, which may also load the pinned Chart.js file.
  • The server only answers requests addressed to the host names it is configured for (localhost and 127.0.0.1 by default), so another website cannot reach it through your browser.
  • Data is stored in SQLite on your own computer, or in PostgreSQL when run with Docker Compose or on a server.
