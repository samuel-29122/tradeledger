About these figures

  • Open trades: {{ report.open_trades }} {{ "trade is" if report.open_trades == 1 else "trades are" }} open and excluded from every figure above.
    • {% if report.unknown_close_time_trade_ids %}
  • Unknown exit times: {{ report.unknown_close_time_trade_ids | length }} closed {{ "trade was" if report.unknown_close_time_trade_ids | length == 1 else "trades were" }} recorded before exit times were tracked (#{{ report.unknown_close_time_trade_ids | join(", #") }}). {{ "It is" if report.unknown_close_time_trade_ids | length == 1 else "They are" }} placed at {{ "its" if report.unknown_close_time_trade_ids | length == 1 else "their" }} entry time, an approximation that can move {{ "it" if report.unknown_close_time_trade_ids | length == 1 else "them" }} into an earlier day or month.
    • {% endif %} {% if report.r_unavailable %}
  • No usable R: {% for item in report.r_unavailable %}trade #{{ item.trade_id }} ({{ item.reason }}){{ ", " if not loop.last }}{% endfor %}. These count in win/loss figures and money, but not in R figures or charts.
    • {% endif %} {% if report.excluded %}
  • Could not be evaluated: {% for item in report.excluded %}trade #{{ item.trade_id }} ({{ item.reason }}){{ ", " if not loop.last }}{% endfor %}.
    • {% endif %}
  • Running peak and drawdown: the running peak is the highest cumulative R reached so far, starting from 0R. Drawdown is the running peak minus the current cumulative R. Maximum drawdown is the largest such fall. Total realised R is simply where cumulative R ends.
  • Units: R-multiples compare trades of any size and currency. Money is shown per quote currency only.
  • Sample data: the trades loaded by flask --app tradeledger seed-db are synthetic, for demonstration only.
  • Charts: drawn by Chart.js {{ chart_js.version }} from exact values calculated in Python. Positions on a chart are approximate; the tables and text are the reference.
